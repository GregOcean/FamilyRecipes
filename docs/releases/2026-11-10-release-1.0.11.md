# 家肴 1.0.11 部署 SOP

版本：1.0.11 (12)，沿用原正式签名。包含米白厨师帽/浅米杏底图标和开屏、移除底部版本号、消息通知入口移至设置、聊天记录搜索及离线缓存回退。聊天搜索需要同时更新后端和 App。

本次没有新增数据库迁移；发布脚本仍执行历史可重复迁移。不要清库、重新导入菜谱，或运行 schema.sql/data.sql。现有邮件、AI 配置和回填队列保留；本次不额外排队全量回填。

## 1. Mac 校验并上传

本次发布包已由 prepare-release.sh 构建；不必重复打包。

```bash
cd /Users/wangyang/Documents/personal_projects/FamilyRecipes
(cd familyrecipes-release/1.0.11 && shasum -a 256 -c SHA256SUMS)
ssh root@152.42.242.92 'mkdir -p /root/familyrecipes-release/1.0.11'
scp familyrecipes-release/1.0.11/* root@152.42.242.92:/root/familyrecipes-release/1.0.11/
ssh root@152.42.242.92
```

提示密码时输入服务器 SSH 密码。若本地校验失败，先停止，不上传。

## 2. 服务器部署

```bash
cd /root/familyrecipes-release/1.0.11
bash deploy-current-server.sh 1.0.11
```

必须看到「发布成功：1.0.11」。脚本自动备份数据库、JAR、APK 和 Nginx，更新后端和官网下载包，健康检查后更新真实发布时间。官网资源包含在 JAR 内，不必另外上传 HTML。后端重启期间会短暂不可用。

若报错，不继续反复部署；保留完整错误和备份路径。脚本在应用更新阶段失败会尝试恢复旧应用，但数据库迁移不自动回滚，不要直接恢复数据库覆盖新数据。

## 3. 验证服务器

```bash
systemctl status familyrecipes --no-pager -l
curl -fsS https://familyrecipes.live/apk/release.json
```

确认服务正常、release.json 的 version 为 1.0.11。失败时查看：

```bash
journalctl -u familyrecipes -n 80 --no-pager
```

## 4. 手机验收

从 https://familyrecipes.live/ 刷新后下载覆盖安装，无需卸载。设置中应为 1.0.11 (12)。

- 开屏与桌面图标：浅米杏背景、米白厨师帽。
- 底部无版本号；设置保留版本和通知入口，消息页不再显示开启通知按钮。
- 输入曾发送的聊天内容，结果显示所在群、发送者、时间及内容；点击定位到对应消息。
- 多于 50 条结果可以加载更多；清空搜索返回群列表。
- 先联网打开群同步历史，再断网搜索。提示仅检索本机缓存，未缓存内容不会显示；恢复网络后点重新搜索在线记录。
- 搜索文字/链接消息原文，暂不识别表情包图片里的字或按翻译结果检索。

发布前本地后端 82 项测试通过，Android 单元测试与 Debug 构建通过。正式包另校验 SHA-256 和签名兼容性；这不代替手机验收。
