# 家肴 1.0.18 发布

版本：`1.0.18` / `versionCode 19`。此次需要同时更新后端和 Android App；本地打包不代表已部署到服务器。

## 修改内容

- 首页移除“发现 / 我的菜谱”切换行，搜索入口与厨房选择并排。
- 来源、菜系、口味、耗时、库存全部支持多选。同类选项取并集，不同类别取交集；清空表示不限。选择后按确定生效，取消保留原选择。
- 来源包含我的菜谱、我会做、我的收藏、分享给我，保留原有菜谱访问权限。库存筛选使用当前厨房的有效库存。
- 首页上滑加载更多，保留下拉刷新；移除独立“加载更多”按钮。
- 收紧侧栏、库存卡片和筛选区；安排保留点菜、备菜两个入口，草稿分别归入对应类型。

## 在 Mac 发布

已准备好的发布包位于 `familyrecipes-release/1.0.18/`，直接运行：

```bash
cd /Users/wangyang/Documents/personal_projects/FamilyRecipes
bash scripts/publish-release.sh 1.0.18
```

按提示输入服务器 SSH 密码。脚本会上传并校验文件，备份数据库和旧版本，执行已有的可重复迁移，更新后端并等待健康检查，通过后更新官网下载 APK 和发布时间。看到“发布成功：1.0.18”才表示部署完成。

无需清理数据库、重新导入菜谱或重新执行 LLM 打标。沿用已有邮件、AI 和管理员配置。

## 安装与验收

1. 打开 https://familyrecipes.live/ 刷新，确认版本为 1.0.18，下载覆盖安装。
2. 首页不再显示发现/我的菜谱按钮；厨房旁边可以搜索。
3. 口味选择酸和辣，确定后再次打开确认勾选保留；取消修改不应影响已有筛选。
4. 同时选择多个来源、菜系、耗时，验证结果；清空全部筛选应恢复不限。
5. 切换厨房，库存筛选随当前厨房变化；未登录选择个人来源或库存时提示登录。
6. 检查上滑加载、下拉刷新，以及英文界面的筛选标题和选中值。

线上版本和健康检查：

```bash
curl -fsS https://familyrecipes.live/apk/release.json
curl -fsS https://api.familyrecipes.live/api/config/catalog-summary
```

若部署报错，在服务器查看日志：

```bash
systemctl status familyrecipes --no-pager -l
journalctl -u familyrecipes -n 100 --no-pager
```
