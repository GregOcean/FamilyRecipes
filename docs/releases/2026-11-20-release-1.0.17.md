版本：`1.0.17` / `versionCode 18`。本地已准备发布包；服务器 SSH 需要交互输入密码，本次没有自动上传或部署。

## 内容

- 修复聊天分享点菜、备菜、菜谱卡片越界，调整卡片层次、分类色标及菜品列表。
- 收紧常用按钮、快捷菜单和底部操作区，保留点击区域与大字体适配。

- 后端同时包含管理后台补充任务的 `recipe_ids` / `recipe_id` 字段修复，并兼容旧浏览器页面字段。

## 在 Mac 发布

```bash
cd /Users/wangyang/Documents/personal_projects/FamilyRecipes
bash scripts/publish-release.sh 1.0.17
```

按提示输入服务器 root 的 SSH 密码。脚本上传到现有 `152.42.242.92`，校验文件、备份数据库及旧版本、执行现有可重复迁移流程、更新后端并等待健康检查，通过后发布 APK 和真实下载时间。无需清库或重新导入菜谱，沿用邮件、AI 与管理员配置。

只有看到“发布成功：1.0.17”才表示完成。发布失败时保留终端最后的错误；不要卸载手机 App 或删除数据库。

## 安装验收

1. 打开 https://familyrecipes.live/ 并刷新，确认展示 1.0.17，下载并覆盖安装；沿用原签名，不必卸载旧版。
2. 群聊发送已有点菜、备菜、菜谱，检查卡片宽度、长标题、菜品列表和点击跳转。
3. 检查分享菜单、添加菜单、食材保存及菜谱底部按钮；切换英文和夜间模式。
4. 管理后台 https://familyrecipes.live/admin/ 强制刷新，选择一道菜开始补充，确认进入队列。

线上版本验证：

```bash
curl -fsS https://familyrecipes.live/apk/release.json
curl -fsS https://api.familyrecipes.live/api/config/catalog-summary
```
