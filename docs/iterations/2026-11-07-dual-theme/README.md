# 1.0.4 浅色/深色主题

替代尚未发布的临时 1.0.3 强制浅色方案。默认跟随系统，设置→外观可选跟随系统、浅色、深色，保存到独立偏好并使用 AppCompat 夜间模式重建页面。继续禁用系统强制变暗，使用自定义完整配色而不是颜色反转。

资源中增加 surface、outline、on_primary 与辅助卡片色，values-night 定义深蓝灰背景和浅色文字。程序创建的 Ui 控件按实际夜间偏好读取同一组资源。输入框中等字重，提示移到 helperText。清理主导航、卡片、库存、头像、聊天、搜索和菜单的固定浅色背景；顶栏保持深底白字，按钮与菜谱标签使用对应 on_primary。

验证：assembleRelease、testReleaseUnitTest；正式签名校验；android/scripts/check-theme-contrast.py 验证16组文字/背景组合均至少4.5:1。模拟器实测系统明暗切换时食材表单正确变色，示例不重叠；系统浅色时手动选择深色生效；截图检查设置与菜谱详情。最后根据截图修正标签文字及顶栏菜单图标后重新构建。并未逐一对所有页面所有交互完成真机验证，vivo 厂商模式仍待用户复验。
