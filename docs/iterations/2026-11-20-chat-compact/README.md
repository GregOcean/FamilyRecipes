# 聊天分享卡片与紧凑操作区

## 修复与样式

- 聊天列先为头像预留宽度，再分配剩余空间。新增 `ChatBubbleLayout` 对整张气泡（包括分隔线）限制宽度，最大 320dp，不再用屏幕宽度推算单个文字控件的上限。
- 点菜、备菜、菜谱分享使用主题表面色、轻边框与分类色标。标题最多两行，展示前三道菜及总数，底部保留查看入口。普通文字、链接、长按复制、离线重试、翻译和点击跳转路径保持原有行为。
- 常用 Material 按钮统一采用较紧凑的文字、间距和圆角，至少保留 48dp 点击区域；常规色块约 36dp 高，大字体可增高。次要操作按内容宽度显示，明确指定宽度的工具栏/页签仍遵循原布局。
- 通用快捷入口从图标在上、文字在下改为横向排列，默认最小高度从 104dp 降到 56dp，影响聊天分享、首页添加与个人页快捷入口。聊天菜单取消固定高度，英文可自动换行。
- 收紧菜谱底部操作区、食材保存、登录、二维码保存、侧栏菜单和底部导航的空白。
- 视觉验收同时修复夜间聊天输入框白底、返回箭头黑色、菜谱分享图标被单色着色成实心块，以及两倍字体下头像首字裁切。

## 验证

- 原实现：真实 Android 320dp 布局下，发送的点菜卡片左边界为 -50px，回归测试失败，复现越界。
- 修复后：33 项 Android 单元测试通过；Debug APK 与仪器测试 APK 构建通过。
- 2 项 Android 仪器测试通过。卡片测试组合覆盖中文/英文、深浅色、1/1.3/2 倍字体、320/360/600dp 宽度、发送/接收，以及点菜/备菜/菜谱/普通长消息，共 288 种布局。逐层断言没有水平越界、文字没有垂直裁切。
- 按钮测试验证 48dp 点击区域、正常字体下不过高、英文及两倍字体换行。主题文字对比度检查通过；修正了旧脚本将工具栏前景硬编码为白色的过时检测项。
- 截图是 Android API 37 模拟器用真实布局、适配器与固定消息样例渲染的结果，不代表新建了真实群消息。没有调用生产接口、收费模型或修改服务器。
