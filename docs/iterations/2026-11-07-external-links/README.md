# 多外链与表情发送调整

## 已实现
- 每份菜谱支持最多 30 个外部链接。每条保存标题、URL、平台、可选缩略图、自由备注和顺序。
- 编辑页可修改标题及备注（最多 2000 字）、上移、下移、删除；草稿保存这些信息。详情页按保存顺序展示备注。
- 服务端以提交数组的顺序为准生成 sort_order，查询按 sort_order、id 排序。原有访问和编辑权限继续生效。
- 按真实 URL 域名匹配微信视频号、微信公众号、微信、抖音、小红书、下厨房、YouTube、Instagram、Facebook、哔哩哔哩、美食杰、豆果美食。未知平台显示“网络”；不按分享文案或查询参数猜来源。平台识别不代表可抓取正文或视频。
- 表情面板嵌在聊天页面底部，输入栏及发送按钮位于面板上方。点击表情在光标处插入，可连续输入，最后统一发送；文本和表情一起保存草稿。返回键优先关闭面板，点击输入框切回键盘。从相册发送逻辑不变。
