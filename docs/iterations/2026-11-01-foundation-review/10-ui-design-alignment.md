# 一级页面与设计稿对齐检查

参照已确认的 `jiayao-refined-pages.html` 湖蓝大字版原型。本轮处理原生 Android 界面与原型的明显偏差，不修改后端权限规则。

| 页面 | 原偏差 | 本轮调整 |
| --- | --- | --- |
| 菜谱 | 默认标签含糊、重启恢复窄筛选、换一批占整行、图片四周留白过多 | 新会话口味/耗时/食材均不限；当次旋转保留选择；标题同行换一批；封面铺满卡片上部、增加正文内边距与卡片间距、分色插画底 |
| ＋ | 四项只有文字 | 食材/菜谱/点菜/备菜恢复线性矢量图标和四色入口，保留继续草稿 |
| 我的 | 旧个人页拼接长按钮 | 头像资料、真实菜谱/收藏/会做统计、2×2 快捷入口、可访问厨房列表、账户工具分区 |
| 库存 | 每个物品占大块空间 | 紧凑白色条目；数量、分类和位置归组；到期和更多保留；搜索与分类入口对齐主题 |
| 安排 | 所有标签同色、新建按钮独占整行 | 明确选中态；备菜/点菜/草稿分别显示标题；新建入口放在标题旁 |
| 消息 | 纯文字大块与两行大按钮 | 标题旁发起群聊；图标+群名+消息预览条目；食材提醒入口 |

## 交互与数据

- 个人页“我的点菜”“我的备菜”“草稿箱”分别进入对应标签，不再全部跳同一页。
- 个人统计使用真实 API；请求失败显示重试，不伪装为 0。
- “分享给我的”可选择共享菜谱或点菜/备菜入口。列表沿用实际访问权限。
- 已存在的厨房、账号、草稿和菜谱数据不清空。
- 原型中的演示人物、菜单、厨房成员数不填入真实账号；头像当前仍使用默认向日葵。资料编辑未在本轮补做，不保留无效的“即将上线”按钮。
- 主入口保持可读标签与至少 48dp 点击区域。此轮不等于已完成所有字体倍率、平板和深色模式适配。

## 验证

- Android `assembleDebug` 与 `testDebugUnitTest` 通过（5 项）。
- 模拟器对照实际页面检查默认筛选、个人页、四项新增入口、库存、安排与消息；检查图标对比度、文本截断、导航去向。
- 后端未修改，本轮不重复后端测试。
