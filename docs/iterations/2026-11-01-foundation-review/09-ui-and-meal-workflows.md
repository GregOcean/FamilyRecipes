# 09 · 湖蓝界面与点菜、备菜流程

日期：2026-11-01。依据本轮可点击设计及用户确认，落实到 Android 与 Spring Boot；这份记录只描述本轮增量。

## 界面与导航

- 底部为菜谱、库存、＋、安排、消息；头像进入“我的”，左侧工具栏提供厨房/群组、扫码、二维码及设置入口。
- 使用湖蓝、浅蓝和白色，主要文字 16–20sp，主要操作至少 48dp；顶部保留紧凑的厨房切换。
- 菜谱没有照片时显示食物图案，不把个人头像当成菜谱封面。
- 菜谱页分发现和我的菜谱。口味、耗时、缺料数量是筛选条件；我创建/收藏/共享、我会做是个人范围条件。搜索在当前条件下替换结果，有关键词时不显示换一批。
- 发现排序结合收藏标签、个人烹饪历史和可变化的随机种子；服务端先过滤权限与条件再分页，避免前端只筛当前一页。
- 页面搜索请求取消旧任务并检查版本和厨房；成功结果与条件按账号、服务地址、厨房保存，刷新失败时保留上次列表。

## 菜谱、改编、记录

- 新建和编辑仍使用全屏 Activity；增加食材用量、耗时、口味、可增删/上移的步骤及步骤图。
- 食材按“名称 | 用量”逐行填写，保存时匹配或创建食材库条目。图片仍使用现有本地上传服务与元数据分类。
- 编辑内容自动进入账号隔离的本地草稿；返回、失败后可继续。保存期间禁用编辑，避免请求中途改动导致内容丢失。
- 收藏保留原菜谱引用；“改成我的做法”创建私有完整副本，保存来源 ID 与名称，并复制本地图片所有权。原菜谱修改、删除不会覆盖副本或清理其图片。
- “我会做”是个人标记，与是否收藏、是否创建相互独立。
- 做菜记录包含日期、心得和过程/成品照片，只展示当前用户自己的记录；记录编辑也保留本地草稿。

## 点菜与备菜

- `meal_arrangement` 保存菜单类型、标题、可选日期/餐次、菜名快照与可选菜谱 ID、采购项与勾选状态、可选来源菜单 ID。
- 点菜和备菜均可独立创建；从点菜创建备菜也会得到独立内容。
- 草稿保存在本机 Room，正式菜单保存在后端；不会自动发送到群聊。
- 分享时由创建者选择所在群聊，通过 `meal_share` 记录读取权限并发送菜单链接。群成员可以查看、据此创建自己的备菜；仅创建者可编辑原菜单。
- 分享菜单会静默授予群成员其中菜谱的只读权限（含图片），不改变原菜谱的私有属性和编辑权限；转备菜保留菜谱 ID，并可从“我的菜谱 → 共享”检索。权限随共享菜单当前内容及群成员资格生效，退出群后不再通过该分享授权；已经存在的菜单分享同样适用。
- 更新菜单带 revision；旧版本提交返回 409，防止两台设备静默覆盖。
- “从菜谱中选”打开全屏搜索、多选页，支持分页、口味/耗时/库存等条件；确认后才合并到菜单，保留已有标题、时间和手写菜名。
- 采购建议根据缺少的食材种类补充，保留手动编辑。库存数量仍为自由文本，因此**不做精确数量扣减或单位换算**，需要用户核对用量。

## 库存操作

- 右滑：标记已吃完/用完，移入历史，并提供撤销。
- 长按或可见的“更多”：恢复库存、修改余量、标记丢弃、删除误录。
- 丢弃/删除采用独立状态，不计作吃完；到期刷新和推荐只读取活动库存。恢复时重新计算临期/过期状态。
- 现有食材分类树继续保留，改为分类选择入口，给物品列表留出完整宽度。

## API 与数据

新增接口：

- `GET /api/recipes/browse`
- `POST /api/recipes/{id}/adapt`
- `PUT /api/recipes/{id}/known`
- `GET/POST /api/recipes/{id}/records`
- `GET/POST /api/meals`、`GET /api/meals/{id}`、`POST /api/meals/{id}/share`
- `POST /api/fridge/items/{id}/status`

新库按 `schema.sql` 与 `data.sql` 初始化。已有开发库只需执行一次 `migrations/2026-11-01-ui-workflows.sql`；本机开发库已执行，未清空原数据。内置公共菜谱增加了明确的口味标签，未给用户菜谱猜测标签。

## 验证与本机验收

- 后端：隔离 MySQL 集成测试与单元测试共 41 项通过，包括菜单分享/退出群后权限、共享菜单自动授予菜谱及图片只读权限、转备菜保留菜谱关联、版本冲突、库存丢弃/恢复、菜谱与媒体副本独立、口味+库存+我会做联合筛选。
- Android：`assembleDebug`、`testDebugUnitTest` 通过，5 项单元测试通过；使用 JDK 17、SDK 34。
- 模拟器：新版已安装，本地后端已重启；检查菜谱、库存、安排、消息、四项添加菜单及全屏编辑/菜谱选择页，检查导航、图片占位及筛选文字；修复旧彩色图标染色后成为实心块、文字截断、笔记提示重叠。

建议手动验收：

1. 菜谱中选“酸”，再搜索“土豆”，确认不出现换一批；清空搜索后恢复推荐。
2. 收藏公共菜谱，改成我的做法，修改步骤后确认原菜谱未变。
3. 从＋新建点菜，输入标题后进入选菜页，多选并返回，确认原内容保留；返回后在安排的草稿中继续。
4. 保存菜单，创建独立备菜，生成采购清单并勾选后保存；可选地分享到自己的测试群。
5. 库存右滑后撤销；长按标记丢弃，确认不会进入已吃完历史。
6. 用两个测试账号验收菜单分享权限、群退出后的访问，以及不同厨房的库存约束。

本轮未实现自动抓取视频、AI 生成做法、食材数量单位换算或跨用户编辑同一菜单。扫码和提醒继续复用既有实现。
