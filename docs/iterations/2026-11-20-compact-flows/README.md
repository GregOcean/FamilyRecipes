# 2026-11-20：列表与筛选布局精简

## 改动

- 菜谱列表取消“加载更多”按钮。上滑到底加载下一页；已有内容在失败后保留，再次上滑重试。每次手势至多接受一次请求，刷新/筛选请求期间不追加旧结果，空页终止继续请求。
- 左侧“常用工具”抽屉从最大 260dp 改为 220dp，同时减少内边距。
- 菜谱筛选使用独立的小标题、加粗暖色当前值和下拉箭头；完整选择值可以换行，保留至少 48dp 点击区域。
- 库存搜索下方只保留并排的“食材类别”“过期状态”。状态菜单包含全部在库、未临期、即将过期、已过期、已吃完；保留消耗历史和右滑吃完功能。
- 库存条目合并数量、分类、储存条件；到期状态与日期合并，减少重复标签。保留图片、预留人和更多操作。窄屏与大字体允许自然换行。
- 安排只保留“点菜”“备菜”两个标签。各自下方显示当前厨房对应的本地草稿，保留继续编辑、确认删除功能；旧版缺少厨房字段的草稿继续可见。草稿读取独立于远端列表，断网时仍可打开。
- 全局加号移除草稿入口。安排新建按钮为实心主色，标签为浅色描边，区分动作与切换。
