# 导航、设置与工具页修复

基于 `v0.1.0-baseline`，本轮不修改后端接口、权限或菜谱内容。

## 行为

- 顶部厨房选择改为锚定按钮的下拉列表，标记当前厨房；仅负责切换。
- 侧栏拆分厨房管理、群组管理。厨房管理为完整页面，新增/改名另开表单页；所属群组只允许选自己管理的群组。
- 群组管理统一放置创建入口，消息页的入口改为“管理群组”。群组详情可查看成员、关联厨房、修改自己管理的群名称并打开聊天。
- 侧栏扫码使用方框扫描图标；我的二维码只在个人页提供入口。
- 二维码页补上可见返回图标和无障碍标签。Android 10+ 保存图片直接使用 MediaStore，不再申请过时的写存储权限。
- 浏览记录只在菜谱详情成功读取后保存，按 API 服务和账号隔离，本机最多 200 条；同一菜谱重复访问更新时间，支持清空。记录失败不阻止查看菜谱。
- 设置为独立页面，支持中文/英文、系统字体与显示入口、系统通知权限、食材提醒开关、提前天数和每日时间。提醒仍每天最多汇总一次。
- 使用 AppCompat 应用语言切换和持久化。原先用户默认继续中文；菜谱、厨房/群名称和聊天原文不自动翻译。口味和餐次显示可翻译，但发给后端的枚举保持不变。
- 英文资源覆盖导航、主要操作、表单、工具页和提示。服务器返回的业务错误、食材库/分类内容及中文自然语言识别不是本轮自动翻译范围。

## 验证

- `assembleDebug` 和 `testDebugUnitTest`（5 项）通过。
- 中文与英文资源键完整性检查，534 个键一一对应。
- 模拟器检查厨房下拉、厨房管理列表、浏览记录写入、二维码页面返回和保存至相册。
- 模拟器实测中文→英文、重启后保留英文、再切回中文；提醒按原有 3 天 / 17:00 保存成功并完成系统通知授权；字体入口能打开系统 Display size & text 所在页面。
- 群组列表/成员/关联厨房展示、管理表单、多层返回均检查；新增厨房空名称被阻止，未创建验收用厨房或群组。
- 二维码保存文件在模拟器 Pictures/FamilyRecipes 目录中确认；浏览记录中确认出现刚打开的菜谱。
- 本轮未在真机/平板上验证，也未使用另一账号实际扫描二维码；扫码协议沿用已有个人名片流程。

## 边界

浏览记录保留在本机，不跨设备同步。未移除已经存在的厨房、账号、草稿或收藏。二维码内容仍是个人名片，不是自动加入群聊的邀请凭证。管理页不新增删除厨房或解散群组等破坏性入口。

## 后续修复：扫码与导航样式

- 复现扫一扫进入即崩溃：`ScanQRActivity` 继承 AppCompatActivity，却配置为 ZXing 的平台主题，触发 `You need to use a Theme.AppCompat theme`。入口恢复应用主题，实际相机预览使用独立 ZXing Activity。
- 相机预览保持竖屏并提供左上角返回箭头；恢复入口实例时不重复拉起扫描。
- 管理、设置、浏览记录、点菜/备菜编辑的整行返回按钮改为角落箭头，图形 24dp、触控区域 48dp。
- 厨房下拉改为白底蓝色风格，厨房图标、厨房名/群组名分行、当前项浅蓝背景与勾选标记。
- 服务器线索和部署核对步骤见 [DigitalOcean 部署说明](../../deployment/digitalocean.md)。未改动线上机器。
