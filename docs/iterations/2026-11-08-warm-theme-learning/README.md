# 暖色主题、学习内容、好友邀请与推荐

## 已实现

- 日间暖白、杏桃色底与陶土色强调；夜间暖灰褐底、浅杏色强调。主文字、辅助文字、主按钮和标题栏的两套配色对比度均超过 4.5:1。
- 应用图标：白色圆角电饭煲、顶部控制区、蒸汽、暖色佳肴字样。自适应图标、旧版图标和启动页共用矢量资源。
- 左侧新增“新手入门”“进阶知识”“好友与邀请”。HowToCook 的 15 篇入门与 4 篇进阶文章以及 3 张 SVG 插图离线打包。中文原文、固定 revision、来源与 Unlicense 元数据保留。尚未翻译这批新文章。
- 好友按完整用户名或用户 ID 搜索，响应仅含公开身份信息。发送邀请不建立好友关系；只有接收人接受后才建立双向关系。扫码同样发送邀请。
- “我的做法”打开源菜谱的本地草稿，保存前有明确确认。保存才创建独立菜谱并复制源媒体、继承来源信息；取消不会创建菜谱。草稿继续保留，原菜谱不变。
- 菜谱编辑新增菜系字段、草稿保存菜系；首页包含菜系过滤与甜/麻/咸口味；“酸辣”支持酸、辣两个独立标签共同匹配。
- 推荐入口共用排序：会做 +6、收藏 +5、近 30 天浏览 +2；会做/收藏的同口味菜系最多 +4，浏览相似偏好最多 +2，实践记录最多 +2，踩 -2，随机探索 [0,2)。不再硬排除踩过的菜。登录后真实详情访问才记浏览信号，同一用户同一菜谱只有一行。
- `/data/` 整体忽略，API 密钥文件仍忽略。知识文章作为应用运行资源存入 assets，下载原始数据留在 data。

## 数据仍有明确缺口

- 缺少证据的口味、菜系填“待确认”，不把未知当清淡，也不把 HowToCook 的所有菜误认成中餐。
- `classify_catalog.py` 是本地批量打标入口，默认 dry-run、默认上限 3；只有显式 `--apply` 才调用模型。当前没有执行付费打标或全量翻译，没有导入线上。
- 打标结果包含模型、推断标记与证据；仍需人工抽查，不等同于权威分类。
- Wikibooks 继续慢速下载，60 秒请求间隔，遵守服务端重试时间。图片仍受 429 限流，未宣称完整。
- HowToCook 图片解析修复带括号文件名，恢复了 4 个图片引用。

## 部署前

除上一轮 `2026-11-08-translations.sql` 外，需要执行
`backend/src/main/resources/migrations/2026-11-08-recommendation-signals.sql`。
它创建浏览信号表并补齐历史菜谱缺失分类的“待确认”标记，不清空数据。
好友继续使用原有 friendship.pending 状态，不需要新表。
